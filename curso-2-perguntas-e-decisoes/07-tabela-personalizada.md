# Atividade prática: Criar uma tabela de dados personalizada

## Visão geral da atividade

Nesta atividade, você usará uma Planilha para criar uma tabela de dados personalizada e analisar seus dados com funções. Para começar, suponha que você seja um Analista de dados que trabalha para uma agência de recrutamento. Essa agência de recrutamento ajuda todo tipo de empresa a encontrar pessoas qualificadas para preencher vagas de Análise de dados abertas. A agência coletou dados sobre aplicações de emprego para oportunidades publicadas em seu site ao longo de um ano. 

---

## Cenário

A Agência pediu à sua Equipe que otimizasse o processamento de aplicações on-line. Sua tarefa é resumir os dados de aplicações de emprego da agência. Em particular, você deseja responder às seguintes perguntas: 

- Qual foi o número total de aplicações recebidos por mês?

- Quantos aplicações foram recebidos?

- Em quais meses foram recebidos o menor e o maior número de aplicações? 

- Qual foi o número médio de aplicações recebidos por mês?

Para fazer isso, você trabalhará com uma Planilha. Usará as Funções da Planilha para fazer cálculos com base nos dados e criará uma tabela de dados personalizada para resumir os resultados. 
Ao concluir esta atividade, você será capaz de importar um arquivo de planilha, classificar dados, criar uma tabela de dados personalizada e usar funções de planilha para trabalhar com seus dados. As Planilhas são uma ferramenta essencial para todo Analista de dados. Usar planilhas para organizar e analisar dados é uma habilidade importante que você continuará a desenvolver ao longo de sua carreira.

---

## Reflexão

**Como o uso de funções o ajuda a obter insights rapidamente sobre grandes quantidades de dados?**

**Como a criação de uma tabela de dados o ajuda a organizar e comunicar aspectos importantes de seus dados?**  

---

## Minha Resposta

O uso de funções nas planilhas me ajuda a ser mais prática, produtiva e obter resultados de cálculos com mais precisão. As funções são métodos predefinidos que auxiliam os analistas de dados a obterem informações fundamentais (insights) que contribuam para uma análise específica de situações empresariais, educacionais, institucionais, de informática, financeiras e muito mais. O uso das funções juntamente com uma boa formatação dos dados de resumo me ajuda a compreender melhor o estudo de caso, o encontro de padrões, possíveis causas desses padrões e como resolvê-los ou até melhorá-los. Organização é a chave do sucesso, e isso também vale para a área de análise de dados. Com uma grande quantidade de dados brutos, seria extremamente complicado e arriscado analisá-los sem que passem por algum tipo de tratamento e organização. Não é apenas filtrar as informações das quais eu quero obter insights, é saber aproveitar meu tempo de forma eficiente e fornecer às partes interessadas informações claras e diretas. 

Por isso, usar fórmulas e funções para criar uma tabela de dados de resumo é uma boa prática a se seguir e também uma prática mais segura, garantindo informações transparentes e tomadas de decisões eficazes. Uma tabela de dados resumidos mostra de forma direta e organizada quais dados e quais cálculos são necessários para responder às perguntas estabelecidas nas etapas do projeto de análise.
