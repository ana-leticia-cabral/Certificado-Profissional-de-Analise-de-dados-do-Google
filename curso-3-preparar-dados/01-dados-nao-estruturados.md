# Autorreflexão opcional: Dados não estruturados

## Visão geral da atividade

Agora que você aprendeu sobre dados não estruturados e formatos de dados, pare por um momento e pense sobre os dados não estruturados e como eles se comparam aos dados estruturados. A maioria dos dados que estão sendo gerados atualmente é não estruturada e a capacidade de entendê-los permite que as empresas descubram padrões ocultos, tendências e informações importantes que podem ser inacessíveis por meio da análise tradicional de dados estruturados. Responder às perguntas desta autorreflexão ajudará a reforçar o que você aprendeu e permitirá que você aproveite ao máximo todos os tipos de dados ao longo de sua carreira.

---

## Cenário

Nesta autorreflexão, você explorará e refletirá sobre a natureza dos Dados não estruturados por meio da interação com um conjunto de dados de origem coletiva no site Quick, Draw!

Quick, Draw! é um jogo em que as pessoas criam desenhos. O Quick! Draw usou esses desenhos para acumular um conjunto de dados que contém milhões de imagens separadas em categorias como plantas, animais ou veículos. No site do Quick, Draw!, você pode examinar esses desenhos ou jogar o jogo para adicionar seus próprios desenhos. Esses desenhos ajudam a treinar computadores para reconhecer objetos com inteligência artificial. 

Nesta autorreflexão, você explorará o site Quick! Draw e criará seus próprios desenhos. Em seguida, você refletirá sobre o conjunto de dados do Quick! Draw e o que você pode deduzir sobre a natureza de Dados não estruturados versus dados estruturados. 

---

## Reflexão

**O que você notou ao explorar os desenhos em diferentes categorias? Há temas consistentes entre as imagens em uma categoria?**

**Se você não conhecesse os rótulos das categorias, como distinguiria as imagens umas das outras? O que você procuraria?**

**Como você descreveria os rabiscos do Quick, Draw! que explorou do ponto de vista dos dados? Por exemplo, como esses rabiscos são organizados? Seria possível armazenar esse tipo de dados em um banco de dados?**

**De que forma esses rabiscos são diferentes ou semelhantes a outros tipos de dados que você encontrou?**

**O que faz com que esses dados não sejam estruturados?**

---

## Minha Resposta

Percebi que, para cada categoria, há um conjunto de desenhos que apresentam traços semelhantes, embora não sejam perfeitos ou idênticos. Ou seja, existem temas consistentes entre as imagens de uma mesma categoria.

Para distinguir as imagens umas das outras, é necessário perceber e observar diferentes padrões nas linhas desenhadas. Eu começaria procurando esses padrões: se dois desenhos apresentam rabiscos que conduzem a um objeto em comum, concluo que eles pertencem à mesma categoria; caso contrário, pertencem a categorias diferentes.

“Quick, Draw!” é uma página web que contém milhões de desenhos distribuídos em diversas categorias. Por se tratar de um grande conjunto de dados não estruturados, ou seja, dados que não são organizados de forma facilmente identificável, eles podem ser classificados como Big Data, devido ao grande volume de dados gerado constantemente. Sim, seria possível armazená-los em um banco de dados, desde que seja um banco apropriado para dados não estruturados, conhecidos como bancos de dados NoSQL. 

Os rabiscos podem ser semelhantes ou diferentes de outros tipos de dados, dependendo da forma como são organizados. Eles se diferenciam dos dados estruturados, que são organizados em linhas e colunas, mas se assemelham a imagens ou fotos, que também não seguem esse tipo de organização. 

O que torna esses rabiscos dados não estruturados é o fato de não possuírem um formato predefinido. Dados não estruturados são mais complexos de analisar e exigem ferramentas específicas para seu processamento.
