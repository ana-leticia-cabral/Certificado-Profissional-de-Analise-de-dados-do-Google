# Atividade prática: Conjuntos de dados do Kaggle

## Visão geral da atividade
Na última atividade, você se configurou no Kaggle e explorou o recurso Notebooks. Nesta atividade, trabalharemos com um recurso diferente da plataforma Kaggle: conjuntos de dados.

A Kaggle tem dezenas de milhares de conjuntos de dados que estão disponíveis para uso público. Qualquer pessoa pode fazer upload de um conjunto de dados para a Kaggle. Se optarem por torná-lo público, outros Kagglers poderão usar esse conjunto de dados para criar seus próprios projetos.

Primeiro, você fará um tour por um conjunto de dados específico. Em seguida, terá a chance de escolher seus próprios conjuntos de dados para trabalhar. Por fim, você usará o que aprendeu neste Módulo para determinar o tipo de dados em seus conjuntos de dados e se os dados são viés de dados ou não.

Ao concluir esta atividade, você será capaz de usar muitos dos recursos úteis que o Kaggle tem a oferecer. Isso permitirá que você encontre dados para projetos e se envolva com a comunidade de dados, o que é importante para o desenvolvimento de habilidades e a rede de computadores em sua carreira como Analista de dados.

## Minha Resposta
Os dois conjuntos de dados que escolhi foram student-performance e spotify-global-music-dataset-2009–2025. O primeiro conjunto de dados contém um arquivo CSV com registros detalhados sobre o desempenho de cada aluno, incluindo informações como horas de estudo, pontuações anteriores, participação em atividades extracurriculares, horas de sono, quantidade de questionários praticados e índice de desempenho. O objetivo desse conjunto de dados é reunir fatores pessoais e acadêmicos que influenciam o aprendizado individual do aluno e o cálculo de seu desempenho. 
O segundo conjunto de dados é composto por dois arquivos CSV: o primeiro apresenta faixas modernas e artistas referentes ao ano de 2025, enquanto o segundo reúne faixas clássicas e populares dos principais artistas entre os anos de 2009 e 2023. O intuito desse conjunto de dados é evidenciar informações como nome da faixa, popularidade da música, nome do artista e sua respectiva popularidade, entre outras características relevantes para pesquisas sobre o mercado musical. 
Esses conjuntos de dados não apresenta viés, visto que as informações coletadas não favorecem nenhum dos lados, ou seja, não toma partido. 

Eu usaria os conjuntos de dados do Kaggle para praticar e aprofundar a compreensão sobre os tipos de dados e sua importância no contexto educacional e profissional. Incorporar essa prática à rotina de estudos permitirá que eu aprenda a selecionar, analisar e extrair insights de forma mais produtiva e organizada, pois conhecer apenas a teoria não é suficiente. O aprendizado se consolida, de fato, por meio da prática constante e da análise. Dessa forma, pretendo utilizar esse recurso do Kaggle para me adaptar à área de análise de dados, aprendendo com os erros e os acertos ao longo do processo.
