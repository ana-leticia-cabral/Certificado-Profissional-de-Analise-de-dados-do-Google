# Atividade prática: Limpeza de dados em planilhas com classificação e filtragem

## Visão geral da atividade
Até agora, você já foi apresentado à Limpeza de dados em planilhas, bem como às principais habilidades em planilhas, como Classificação e Filtragem. Nesta atividade, você usará a Classificação e a Filtragem para limpar um conjunto de dados sujo.

A Limpeza de dados corrige ou remove dados incorretos, ausentes e defeituosos. A Limpeza de dados é de importância crítica porque uma análise baseada em dados sujos pode levar a conclusões erradas e decisões ruins. Quanto mais limpos forem os dados, melhores serão os resultados.



## Cenário
Para esta atividade, imagine que você é um Analista de dados que trabalha para o superintendente de um grande distrito escolar público em Portugal. O superintendente quer saber quais fatores afetam as notas dos alunos nas principais disciplinas e quais Mudanças podem ser feitas para melhorar o desempenho dos alunos. Sua Equipe vai analisar os dados de desempenho dos alunos do ensino médio em duas escolas públicas portuguesas, Gabriel Pereira (GP) e Mouzinho da Silveira (MS). Os dados foram coletados pelo distrito escolar por meio de relatórios acadêmicos e pesquisas com alunos. Os dados incluem Informações como:

- Notas dos alunos

- Informações sobre o histórico do aluno

- Tempo de estudo do aluno

- Participação do aluno em atividades extracurriculares

Entretanto, antes de analisar os dados, é importante certificar-se de que os dados estejam limpos. A análise de dados ruins ou sujos pode fazer com que o distrito escolar chegue a conclusões erradas e implemente Mudanças ineficazes. Sua tarefa é ajudar a limpar os dados.

Ao concluir esta atividade, você será capaz de classificar os dados de diferentes maneiras, aplicar filtros para remover dados incorretos e preencher dados ausentes e converter dados de texto em formato numérico. A Limpeza de dados é uma fase crítica do Processo de análise de dados. A Classificação e a Filtragem são técnicas úteis para a Limpeza de dados e também são habilidades chave que você utilizará em toda a sua carreira como Analista de dados.



## Reflexão
- Por que a Limpeza de dados é uma parte tão importante do Processo de análise de dados?

- Como a Classificação e a Filtragem podem ajudá-lo a limpar os dados com mais eficiência?



## Minha Resposta
A limpeza de dados é fundamental para garantir que os dados utilizados sejam organizados, eficientes, corretos e seguros em todo o processo de análise e tomada de decisão. Dados limpos fazem com que as decisões baseadas em dados sejam menos propensas a apresentar resultados fora do esperado, preservando a credibilidade das informações e evitando prejuízos para empresas e pessoas, sejam elas clientes ou funcionários. 

A classificação dos dados permite a visualização de informações numéricas em ordem crescente ou decrescente, bem como de informações textuais em ordem alfabética. Isso possibilita uma melhor organização dos dados de acordo com as necessidades de cada projeto de análise. Além disso, a filtragem dos dados permite acessar apenas as informações essenciais para determinado momento ou objetivo, ocultando o restante. Dessa forma, os analistas conseguem acessar as informações de maneira mais rápida e com menor propensão a erros. Logo, essas práticas são ótimas formas de transformar dados “sujos” em dados limpos de maneira eficiente.
