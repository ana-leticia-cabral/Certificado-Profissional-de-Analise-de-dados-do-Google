# Atividade prática: Introdução ao BigQuery

## Visão geral da atividade

Recentemente, você foi apresentado ao BigQuery, um data warehouse no Google Nuvem que os analistas de dados usam para consultar, filtrar grandes conjuntos de dados, agregar resultados e realizar operações complexas. Nesta atividade, você explorará a interface do BigQuery, fará upload de dados públicos para o seu console e escreverá algumas consultas SQL simples usando SELECT, FROM e WHERE. 

Ao concluir esta atividade, você estará mais familiarizado com a escrita de consultas na interface do BigQuery. Isso lhe permitirá praticar SQL, o que é importante para trabalhar com bancos de dados em sua carreira como Analista de dados.

## Reflexão

**Como você acha que pode usar conjuntos de dados públicos no BigQuery para ajudar a desenvolver suas habilidades de análise de dados?**

**Como você acha que a compreensão da Sintaxe de consulta básica o ajudará a escrever consultas mais complexas no futuro?**

---

## Minha Resposta

Os conjuntos de dados públicos no BigQuery vão me ajudar a praticar consultas em SQL. Análises que envolvem filtragem e classificação de dados serão aperfeiçoadas. 

Aprender consultas básicas em SQL funciona como uma bússola: ela nos dá uma direção a seguir. No entanto, o caminho a percorrer precisa ser aprimorado conforme as necessidades e os desafios encontrados ao longo do trajeto. Sem uma direção, não há para onde ir.
