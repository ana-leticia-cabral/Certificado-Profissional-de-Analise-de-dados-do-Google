# Atividade prática: Criar uma tabela personalizada no BiqQuery

## Visão geral da atividade

Recentemente, você tem pensado em identificar Fontes de dados bons que seriam úteis para análise. Você também passou algum tempo em uma atividade anterior explorando um conjunto de dados públicos no BigQuery e escrevendo algumas consultas SQL básicas. Além de usar dados públicos no BigQuery, sua futura carreira em dados envolverá a importação de dados de outras fontes. Nesta atividade, você criará uma tabela e um conjunto de dados personalizados que serão carregados em uma nova tabela e consulta. 

Ao concluir esta atividade, você poderá carregar seus próprios dados no BigQuery para análise. Isso lhe permitirá importar suas próprias fontes de dados para o BigQuery, o que é uma habilidade que lhe permitirá analisar com mais eficiência dados de diferentes fontes.

## Reflexão

**Por que o fato de poder usar dados de diferentes fontes é útil como Analista de dados?**

**Como você pode usar tabelas e conjuntos de dados personalizados do BigQuery em seus futuros projetos de análise?**

---

## Minha Resposta

Um analista de dados profissional é aquele que estuda diferentes contextos, bem como variados tipos e origens de dados, aprimorando-se continuamente na resolução de problemas diversos e na construção de respostas para perguntas cada vez mais complexas. 

Posso utilizar tabelas e conjuntos de dados personalizados no BigQuery para treinar diferentes tipos de consultas, explorar múltiplas abordagens de resposta e processar distintos formatos de dados. Todo esse processo contribui para o fortalecimento dos meus conhecimentos e para a evolução contínua em cada projeto de análise de dados.
