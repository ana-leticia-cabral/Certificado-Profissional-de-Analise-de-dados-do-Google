# Atividade prática: Mais prática com SQL

## Visão geral da atividade
Nas lições anteriores, você aprendeu a trabalhar com dados em Planilhas. Agora, você praticará o uso do SQL para trabalhar com dados em bancos de dados. Ao concluir esta atividade, você será capaz de usar o SQL para escrever consultas que recuperam dados de bancos de dados. Além disso, você praticará a navegação em grandes conjuntos de dados públicos no BigQuery para se tornar proficiente em consultas SQL - uma habilidade essencial para sua futura carreira como Analista de dados.



## Cenário 
Nesta atividade, você consultará um conjunto de dados públicos que contém informações sobre as árvores da cidade de Nova York em 2005. Você também usará a função AVG para determinar o diâmetro médio de todas as árvores da cidade de Nova York em 2005. Em seguida, você terá a oportunidade de escrever consultas usando os dados de 1995 e 2015 para comparar os diâmetros médios das árvores.
