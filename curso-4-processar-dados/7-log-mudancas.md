Analise a explicação a seguir sobre a importância dos Logs de mudanças. Em seguida, conclua as instruções passo a passo.



## Reflexão
- O que contribui para um bom Log de mudanças?

- Como você decide se uma mudança é significativa o suficiente para ser incluída no Log de mudanças?



## Minha Resposta
Uma boa comunicação em equipe, aliada à disciplina e à organização por parte do profissional, contribui para a construção de um bom log de mudanças. Além disso, a escolha adequada das ferramentas para o registro das alterações e a correta categorização por versões do projeto e tipos de mudanças realizadas são fundamentais. 

Uma mudança é significativa o suficiente para ser incluída no log de mudanças quando afeta o escopo do projeto, influenciando o trabalho da equipe de dados e os objetivos de negócios, seja para corrigir erros, seja para acrescentar novas funcionalidades.
