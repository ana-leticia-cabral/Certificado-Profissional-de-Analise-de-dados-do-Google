# Atividade prática: Combinar vários dados

## Visão geral da atividade 
Nas atividades anteriores, você adquiriu experiência no uso de funções de planilha para manipulação e limpeza de dados. Nesta atividade, você usará as funções CONCAT e CONCATENATE para ajudá-lo a combinar, de forma rápida e eficiente, várias partes de dados brutos em novos dados.

Ao concluir esta atividade, você será capaz de usar essas funções para combinar dados. Isso lhe permitirá simplificar e condensar dados, o que é importante para o processamento e a Limpeza de dados em sua carreira como Analista de dados.



## Reflexão
- Quais são alguns outros tipos de dados que você poderia combinar usando CONCAT ou CONCATENATE?

- O que acontece se um Analista de dados tentar trabalhar com dados ou nomes que não tenham sido combinados com CONCAT ou CONCATENATE?



## Minha Resposta
Números inteiros ou decimais, datas e horas, valores booleanos e textos puros são tipos de dados que podem ser combinados utilizando as funções CONCAT e CONCATENATE.

O que acontece quando um analista de dados tenta trabalhar com dados ou nomes que não foram combinados depende muito dos objetivos de negócio, da complexidade dos dados e dos respectivos processamentos. Dependendo da análise, dados estruturados dessa forma, em colunas separadas, como nome e sobrenome, podem facilitar o trabalho do analista. No entanto, há situações em que os campos completos são fundamentais para a identificação de dados de caráter único, funcionando como identidades. Em alguns casos, a identidade de um indivíduo é determinada apenas pelo nome e sobrenome, não havendo na base dados como CPF ou outro identificador único. Assim, ao realizar análises cujos resultados podem ser enganosos caso não sejam feitas com base em identidades corretamente definidas, há um risco significativo para o alcance do objetivo de negócio.
