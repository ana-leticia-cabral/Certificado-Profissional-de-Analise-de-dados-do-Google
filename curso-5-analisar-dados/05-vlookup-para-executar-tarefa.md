# Atividade prática: Usar o VLOOKUP para executar uma tarefa

## Visão geral da atividade 
Você aprendeu sobre VLOOKUP, uma função de planilha que procura verticalmente um determinado valor em uma coluna para retornar uma informação correspondente. Nesta atividade, você praticará a Limpeza de dados e usará o VLOOKUP para consolidar informações entre duas guias da Planilha. Você concluirá sua análise criando uma tabela dinâmica.

Ao concluir esta atividade, você será capaz de usar o VLOOKUP para localizar informações em uma planilha e adicioná-las à linha correta em outra planilha. Essa é uma habilidade importante que pode ajudá-lo a trabalhar com grandes conjuntos de dados em sua carreira como Analista de dados.



## Cenário 
Você é o gerente de folha de pagamento em uma empresa de contabilização. Para calcular a folha de pagamento, você precisa saber quantas horas cada um dos seus funcionários trabalhou e a taxa de pagamento por hora. Isso é fácil de fazer manualmente em uma planilha pequena, mas se torna mais difícil à medida que a quantidade de informações aumenta ou se espalha por várias planilhas. Você gostaria de usar a função VLOOKUP como uma forma de automatizar a coleta de informações. Portanto, siga as etapas abaixo para calcular o pagamento semanal total de seus funcionários.



## Reflexão
- Por que é importante limpar e rotular os dados ao usar VLOOKUP e tabelas dinâmicas?

- Quais são algumas outras maneiras de usar o VLOOKUP com os dados dessa tabela?



## Minha Resposta
É fundamental realizar a limpeza e a rotulação dos dados para que o uso de funções, especialmente o VLOOKUP, e de tabelas dinâmicas ocorra de forma mais segura (menos propensa a erros) e organizada, facilitando o entendimento das informações e permitindo que o analista de dados possa utilizá-las e analisá-las adequadamente. 

Nesse cenário, o VLOOKUP pode ser utilizado para retornar informações como a data de contratação do funcionário e o seu status, realizando uma união completa dos dados. Dessa forma, é possível integrar as informações de horas trabalhadas com os detalhes de contratação e pagamento, proporcionando uma visão mais completa e consistente dos dados.
