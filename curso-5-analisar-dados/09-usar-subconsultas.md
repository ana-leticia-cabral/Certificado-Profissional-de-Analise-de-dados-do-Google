# Atividade prática: Usar subconsultas

## Visão geral da atividade 
Como Analista de dados, às vezes você desejará analisar um pequeno subconjunto de dados que está contido em um conjunto de dados muito maior. É nesse momento que as subconsultas podem ser realmente úteis. As Subconsultas são consultas que estão aninhadas dentro de outra consulta. Algumas consultas podem ter muitas subconsultas, enquanto outras podem ter apenas uma. É importante saber como as subconsultas funcionam e entender os diferentes componentes que você pode usar para criá-las.

Nesta atividade, você trabalhará com consultas e subconsultas para examinar um conjunto de dados de saúde pública. Você criará subconsultas para descobrir quais setores recebem um número incomum de reclamações e, o que é mais importante, quais setores estão ligados a problemas graves de saúde. Isso permitirá que você aloque seus Recursos de forma mais eficaz para proteger a saúde pública.



## Cenário
Neste cenário, você é um Analista de dados júnior de um fabricante multinacional de alimentos e bebidas. Você e sua equipe são responsáveis por manter a segurança de uma ampla gama de produtos alimentícios. Devido ao grande número de produtos no mercado, você foi solicitado a priorizar quais produtos precisam ser analisados pelas partes interessadas.

Embora seja útil saber quais indústrias alimentícias recebem mais reclamações, o aspecto mais crítico a ser considerado é identificar as reclamações que levam a consequências graves para a saúde, como visitas ao hospital.

Para concluir essa tarefa, você analisará os Relatórios de eventos alimentares para intervenções de saúde direcionadas. 



## Reflexão
- Por que trabalhar com subconsultas é uma habilidade importante para os Analistas de dados aprenderem?

- Quais são alguns Benefícios do uso de subconsultas?



## Minha Resposta
Trabalhar com subconsultas é uma habilidade extremamente importante, pois permite que o analista de dados pegue uma gama de informações e a divida em partes menores, proporcionando maior produtividade e uma análise mais direta. Isso deixa o código mais organizado, estruturado e de fácil entendimento para que os analistas de dados obtenham as informações de que necessitam. Ou seja, saber recorrer às subconsultas é uma habilidade que todo analista de dados deveria dominar para poupar tempo e acessar somente os dados necessários. Como mencionei em uma atividade anterior, isso se assemelha bastante a um pensamento estruturado ou matemático, que consiste em pegar um problema grande e complexo e dividi-lo em partes menores. Nesse caso, trata-se de pegar um grande conjunto de dados e fazer uma pré-análise, filtrando e classificando partes desse conjunto maior para utilizar apenas as informações necessárias em outra análise, por meio de uma consulta externa. 

Benefícios do uso de subconsultas: estruturação, organização, legibilidade, direcionamento, pensamento matemático, habilidade analítica, praticidade e profissionalismo.
