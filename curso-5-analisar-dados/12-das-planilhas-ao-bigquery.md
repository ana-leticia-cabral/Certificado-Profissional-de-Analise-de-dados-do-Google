# Atividade prática: Das Planilhas ao BigQuery

## Visão geral da atividade

Até agora, você já trabalhou com dados usando planilhas eletrônicas e SQL. Essas ferramentas funcionam de forma muito diferente: Nas planilhas, você pode observar e interagir com os dados diretamente; com o SQL, você interage com os dados por meio de consultas ao banco de dados. Nesta atividade, você usará as planilhas para limpar os dados antes de importá-los para o SQL para análise.

Neste cenário, você trabalha para uma cadeia nacional de lojas como Analista de dados. A gerência está interessada na quantidade de estoque mantida em depósito nas unidades regionais. Seu supervisor pediu que você fizesse uma análise de dados de estoque e vendas para fazer recomendações de mudanças nas práticas de gerenciamento de estoque. Você recebeu três conjuntos de dados com informações sobre estoque, produtos e vendas.

Ao concluir esta atividade, você será capaz de combinar ferramentas para analisar dados com sucesso. Alternar entre planilhas e SQL pode ser um desafio porque são muito diferentes, mas quando estiver mais acostumado com as duas ferramentas, poderá usá-las com mais facilidade. Isso é importante para lidar com projetos maiores e mais complexos em sua carreira de analista de dados.

## Reflexão

**Por que a possibilidade de usar várias ferramentas de análise é útil para alguns projetos?**

**Qual é a diferença entre trabalhar com dados em planilhas e com SQL? Em que aspectos são semelhantes?**

---

## Minha Resposta

Usar várias ferramentas de análise é útil em alguns projetos porque permite que nós, analistas, exploremos conjuntos de dados de diferentes formas, dependendo do contexto associado a esses dados, do tipo de análise e do seu nível de complexidade. Por exemplo, posso ter um conjunto de dados no qual analisar todos os seus componentes em uma planilha facilite meu entendimento sobre o que estou prestes a investigar. Conhecer o conjunto de dados antes de realizar qualquer análise que envolva cálculos e tomadas de decisão importantíssimas é crucial para preservar a confiabilidade da análise. Outro exemplo seria trabalhar com uma grande quantidade de dados extremamente complicada de analisar em planilhas, seja por causar erros, travamentos ou comprometer a integridade dos dados e a produtividade do trabalho. Nesse caso, a melhor opção seria exportar os dados para uma ferramenta que trabalhe com SQL. 

A diferença entre trabalhar com dados em planilhas e com SQL está na capacidade de lidar com dados complexos e na forma de visualização. As planilhas são ferramentas mais amigáveis: nelas, consigo visualizar todo o conjunto de dados estruturado de forma clara, observar colunas e registros, resumir informações com tabelas dinâmicas, gerar gráficos e escrever funções nas células para realizar cálculos necessários para estudo, análise e trabalho. Já no SQL, para visualizar dados estruturados, é necessário realizar consultas que se comuniquem com o banco de dados e retornem resultados de acordo com o que foi solicitado. Por isso, trata-se de uma ferramenta extremamente útil e fundamental para lidar com grandes volumes de dados (big data). No entanto, tanto as planilhas quanto o SQL permitem analisar dados e obter informações acionáveis. Em ambas as ferramentas é possível realizar limpeza, classificação e filtragem de dados.
